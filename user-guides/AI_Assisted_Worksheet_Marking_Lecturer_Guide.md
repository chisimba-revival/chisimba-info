# AI-assisted worksheet marking: lecturer guide

## What this feature does

Chisimba can prepare suggested worksheet marks and feedback for a lecturer. It compares each student's answer with the question, its maximum mark, the model answer and any attached rubric.

AI suggestions are never final marks. A lecturer must review and save them. You can also ignore AI and mark the worksheet entirely by hand.

## Before students begin

### 1. Create or select a rubric

In your course, open **Rubrics**. Create a rubric whose criteria describe the qualities you expect to see in a good answer. Make the performance descriptions specific enough to distinguish strong, adequate and weak work.

A rubric is descriptive guidance; it does not calculate a numeric mark automatically. You remain responsible for deciding the mark within the question's maximum.

### 2. Create the worksheet

Open **Online Worksheets** in the course and add a worksheet. Give it a clear name, instructions and closing date.

While the worksheet is inactive, use **Add / Edit / Remove Questions** to add each question. For every question:

1. Write the question as the student should see it.
2. Enter the maximum mark under **Question worth**.
3. Supply a model answer that identifies the important content and reasoning.
4. Select the most appropriate rubric, if one is available.
5. Save the question.

Review the total mark and preview the worksheet. Activate it only when it is ready for students. Questions cannot be changed while the worksheet is active.

### 3. Add it to the Assessment Plan when required

If the result should appear in Gradebook, open the course **Assessment Plan**, add the worksheet and set its weight. A weight of 0% displays the result but makes no contribution to the course total.

## The student journey

Students open **Online Worksheets**, answer the questions, and choose **Save answers and submit for marking**. Saved drafts are not ready for marking until the student submits them.

After submission, the result is shown as not marked until a lecturer saves the marks. Once marked, the student can see the final score and the worksheet appears as marked in Gradebook.

## Marking without AI

1. Open **Online Worksheets** and select the worksheet.
2. Open a submitted student's attempt.
3. Review the student's answer, model answer and rubric shown for each question.
4. Enter a whole-number mark from zero to the question maximum.
5. Add useful feedback in **Comment**.
6. Choose **Save marks**.

Chisimba validates the entire worksheet before saving. If any mark is missing, not a whole number, below zero or above the question maximum, nothing is saved until all marks are corrected.

## Marking with AI assistance

1. Open the student's submitted worksheet.
2. Choose **Suggest marks with AI**.
3. Chisimba queues the request and shows a progress page. You may leave this page and return later; the browser does not need to remain open.
4. When the suggestions are ready, review every proposed mark and comment against the student's answer, model answer and rubric.
5. Correct anything that is inaccurate, unfair, unclear or inconsistent with your marking approach.

Then choose one of these actions:

- **Approve all AI suggestions** saves all currently displayed marks and comments. Any edits you made before choosing it are included.
- **Save marks** uses the same final saving process and is suitable when you have reviewed or substantially edited the suggestions.

Both actions record the lecturer as the marker. The wording “Approve all” does not bypass lecturer responsibility or validation.

## If AI suggestions fail or take too long

- Choose **Refresh progress** if the request has only recently been queued.
- You can leave and reopen the submitted worksheet later.
- If Chisimba reports a failure, choose **Return to manual marking** and complete the marks normally.
- Do not repeatedly submit the same request. If requests remain waiting, tell the site administrator which course, worksheet and student are affected.

An AI outage never prevents manual marking and never changes a student's saved result by itself.

## Good marking practice

- Treat the suggestion as a draft, not as an answer key or an academic judgement.
- Check that feedback refers to the student's actual answer.
- Apply the same interpretation of the rubric across the class.
- Be alert to unusual terminology, multilingual answers, creative but valid approaches and accessibility needs.
- Do not place confidential information in model answers, rubrics or marking comments.
- Where institutional policy requires disclosure or moderation of AI-assisted marking, follow that policy in addition to this workflow.

## Gradebook checks

After saving, confirm that the worksheet shows **Marked** and the expected percentage in Gradebook. If the percentage is correct but its course contribution is zero, check the worksheet's Assessment Plan weight rather than marking the submission again.

## Quick checklist

- Worksheet inactive while questions are edited
- Appropriate maximum mark for every question
- Clear model answer
- Relevant rubric attached where useful
- Worksheet activated for students
- Worksheet added to Assessment Plan with the intended weight
- Every AI suggestion reviewed by a lecturer
- Final marks and comments saved
- Gradebook result checked
